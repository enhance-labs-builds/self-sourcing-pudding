Self-Sourcing Pudding · two-run tester

Requires macOS or Linux and Python 3.11 or newer.
Open Terminal in this extracted folder. Run:

  bash "Start Pudding.command" --project runs/my-company

Paste your company URL, edit or approve the brief, then vote yay or nay
on at least one candidate. The walkthrough reads your public site and
uses fictional candidates and work emails. It costs US$0. To see the
email column, open the example shortlist CSV linked in README.md.

Run it again with the same project and a new run name:

  .pudding/bin/pudding walk --project runs/my-company --run example-pass-2

Check that already reviewed evidence stays out of your second queue.
The example can have an empty second queue once you review every card.

For real LinkedIn and X searches with work emails, open the live search
section in README.md and set up your own Treg account. Use the same
project to keep your brief and votes. Pudding asks how much you want to
spend before running a live search. If a run is interrupted, use the
printed continuation command to resume it under the same spend limit.
